## Repository Structure

```
proposals/       — Funding requests submitted to the DAO via Snapshot
grants/          — Approved grants (scope, milestones, status, payments)
bounties/        — Open and completed bounties
reports/         — Periodic transparency reports
```

## How It Works

1. **The DAO funds the GBC** via Snapshot vote ([see proposals](./proposals/))
2. **The GBC allocates funds** to grants and bounties by majority committee vote
3. **Everything is tracked here** — every grant, bounty, and dollar spent is documented
4. **Unspent funds carry forward** and are reported in the next funding request
